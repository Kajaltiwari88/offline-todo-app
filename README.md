# Offline Todo

A modern offline-first Todo app built with **Next.js, TypeScript, Tailwind CSS, PouchDB, and CouchDB**.

## ✨ Features

- Create, edit, complete, and delete Todos
- Works offline using PouchDB + IndexedDB
- Automatic CouchDB synchronization
- Search and filter Todos
- Responsive UI

## 🛠️ Tech Stack

**Next.js · TypeScript · Tailwind CSS · PouchDB · CouchDB · Docker**
